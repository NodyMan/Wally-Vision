## 0. Главный способ поиска: SIA2 (проверено 14.11.2026, 13:30)

```
https://irsa.ipac.caltech.edu/SIA?COLLECTION=spherex_dr1&POS=circle+{ra}+{dec}+0.001&RESPONSEFORMAT=CSV
(то же для COLLECTION=spherex_qr3; для глубоких полей — spherex_dr1_deep / spherex_qr3_deep)
```
- WISE 0855: `spherex_dr1` → **258 строк за 9.2 с**; `spherex_qr3` → **0 строк** (1.4 с). Те же 258, что дал TAP, но в 3–6 раз быстрее.
- Нужные колонки: `access_url` (полный URL FITS — не собирать вручную), `t_min` (MJD), `energy_bandpassname` (`SPHEREx-D1..D6`), `em_min/em_max` (м), `obs_id`, `obs_collection`, `s_pixel_scale` (**6.150**), `cloud_access` (JSON: копия в публичном S3 `nasa-irsa-spherex`, `us-east-1`).
- Пример `access_url`: `https://irsa.ipac.caltech.edu/ibe/data/spherex/dr1/level2/2025W19_1B/l2b-v27-2026-197/3/level2_2025W19_1B_0116_1D3_spx_l2b-v27-2026-197.fits`

- QR2 через SIA2 не ищется; DR1 + QR3 его заменяют (официальная документация data access).

**Официальная документация (data products), подтверждено:** пиксель **6.15″**; `IMAGE` в MJy/sr, **ZODI не вычтен** из `IMAGE`; `VARIANCE` в (MJy/sr)²; `WCS-WAVE` — таблица X/Y/VALUES «для визуализации», не все FITS-читатели её понимают, фолбэк — билинейная интерполяция по 4 узлам (~1 нм); для науки — `CWAVE`/`CBAND` из калибровочного продукта Spectral WCS (~32 МБ на детектор); биты FLAGS — **Table 16 в Explanatory Supplement**.

## 1. Запасной способ: TAP (медленнее, но даёт пары детекторов по obsid)

Сервис: `https://irsa.ipac.caltech.edu/TAP` (в Python: `astroquery.ipac.irsa.Irsa.query_tap(sql)`).

Таблицы: `spherex.plane` (метаданные снимка) JOIN `spherex.artifact` (файл) по `planeid`.

```sql
SELECT a.uri, p.obsid, p.energy_bandpassname, p.time_bounds_lower,
       p.energy_bounds_lower, p.energy_bounds_upper, p.datarelease
FROM spherex.artifact a
JOIN spherex.plane p ON a.planeid = p.planeid
WHERE 1 = CONTAINS(POINT('ICRS', {ra}, {dec}), p.poly)
ORDER BY p.time_bounds_lower
```

Полезные колонки `spherex.plane`:

| Колонка | Что это | Пример |
|---|---|---|
| `obsid` | ID экспозиции. **Один obsid = два детектора одновременно** (см. §3) | `01a0cf63-c370-…` |
| `energy_bandpassname` | детектор | `SPHEREx-D1` … `SPHEREx-D6` |
| `time_bounds_lower` | время наблюдения, **MJD** | `60800.700028` |
| `energy_bounds_lower/upper` | диапазон длин волн детектора, **в метрах** | `4.4115e-06` |
| `position_samplesize` | размер пикселя, ″ | `6.15` |
| `datarelease` | дата публикации пакета (еженедельный Quick Release), а **не** имя релиза вроде «QR3» | `2026-10-05 17:28:28` |
| `poly` | контур снимка на небе (для CONTAINS) | |

Полезные колонки `spherex.artifact`: `uri` (относительный путь к FITS), `producttype` (`science`), `releasetype`.

**Скорость:** один TAP‑запрос по точке шёл 20–60 с (в туториале 84 снимка — около 20 с; у нас 5 запросов параллельно — около 60 с каждый). Вывод: **метаданные обязательно кэшировать** (ключ — округлённые ra/dec), холодный `/api/blink` не уложится в синхронный HTTP‑запрос.

**Дубли:** для WISE 0855 каждый `obsid` встречается ровно 2 раза (пара детекторов), дублей между релизами не найдено. На всякий случай дедуплицировать по `(obsid, bandpass)`.

## 2. Cutout (вырезка на сервере)

```
https://irsa.ipac.caltech.edu/{a.uri}?center={ra},{dec}d&size={size_deg}
```
- `size` — **в градусах** (300″ → `0.08333`). В нашем коде FOV в арксекундах, при сборке URL делить на 3600.
- Открывать: `fits.open(url)`. Поднять таймаут: `astropy.utils.data.conf.remote_timeout = 120`.
- Качать параллельно: `ThreadPoolExecutor(max_workers=10)` (в туториале 84 вырезки: последовательно около 2.3 мин, параллельно около 0.2 мин).
- Часть загрузок падает по таймауту (`TimeoutError`, `HTTPError`, `IncompleteRead`, `RemoteDisconnected`): пропускать и ретраить, не валить весь запрос.

**Проверено живой загрузкой (WISE 0855, D6, size=0.0958°):**
- ⚠️ **Ловушка:** под нагрузкой IRSA отвечает **HTTP 200** с `Content-Type: application/fits`, но в теле текст `Server busy, retry later.` (25 байт). Проверять, что тело начинается с `b"SIMPLE"`, и ретраить с паузой 3–12 с. Со второй попытки файл скачался.
- Вырезка 345″ = **56×56 px** (подтверждает 6.15″/px), но весит **≈ 4 МБ** и качается **≈ 12 с**: почти весь объём — PSF‑куб `EPSF`. В кэш класть только `IMAGE, FLAGS, VARIANCE, ZODI, WCS-WAVE`: так кэш в разы меньше, что важно для бесплатного Render.
- Один blink (3 эпохи × 8 снимков = 24 вырезки) — это около 100 МБ трафика и 1–2 минуты даже в 6 потоков. Холодный запрос **только асинхронно**, пресеты — только из кэша.
- Пример `uri`: `ibe/data/spherex/dr1/level2/2026W20_1A/l2b-v27-2026-246/6/level2_2026W20_1A_0033_1D6_spx_l2b-v27-2026-246.fits` (в пути видны релиз `dr1`, неделя `2026W20`, детектор `6`).
- Заголовок: `VERSION = '7.0.5'` (HDU 0); пространственный WCS `RA---TAN-SIP / DEC--TAN-SIP` (reproject понимает SIP); спектральный WCS `CTYPE1W/2W = 'WAVE-TAB'` — табличный, читается только с `fobj=hdul` (нужен слой `WCS-WAVE`).

## 3. Детекторы и спектральные линии LVF (проверено по документации SPHEREx и SIA2)

SPHEREx оснащён шестью детекторами 2048×2048 HgCdTe (H2RG), покрывающими непрерывный диапазон **0.75 – 5.01 мкм**. Непосредственно на фокальной плоскости каждого детектора установлен линейно-переменный фильтр (LVF), плавно меняющий пропускаемую длину волны вдоль одной из координатных осей.

| Детектор | Диапазон λ, мкм | Разрешающая сила R = λ/Δλ | Совместный дихроик-канал | Основные астрофизические маркеры и цели |
|---|---|---|---|---|
| **D1** | 0.746 – 1.117 (0.75–1.12) | R ≈ 41 | D4 | Звёздные фотосферы, оптико-ИК переход, горячие звёзды |
| **D2** | 1.103 – 1.650 (1.10–1.65) | R ≈ 41 | D5 | Звёзды главной последовательности, Barnard's Star, RW Aurigae |
| **D3** | 1.630 – 2.435 (1.63–2.44) | R ≈ 41 | D6 | Звёздная пыль, обертоны CH₄ (1.66 мкм), первый обертон CO (2.3 мкм) |
| **D4** | 2.403 – 3.847 (2.40–3.85) | R ≈ 35 – 41 | D1 | **Фундаментальная полоса льда и пара H₂O (3.0 мкм)**, **фундаментальная полоса метана CH₄ (3.3 мкм)** |
| **D5** | 3.811 – 4.430 (3.81–4.43) | R ≈ 110 – 130 | D2 | **Асимметричное валентное колебание CO₂ (4.27 мкм)**, континуум холодных субзвёздных объектов |
| **D6** | 4.412 – 5.010 (4.41–5.01) | R ≈ 110 – 130 | D3 | **Фундаментальная полоса CO (4.67 мкм)**; **пик фотометрического потока ультрахолодных карликов (WISE 0855, ε Ind B)** |

### Ключевые диагностические молекулярные спектральные линии LVF:
1. **Водяной пар и лёд H₂O (3.00 мкм, Детектор D4):**
   - Фундаментальные валентные колебания связи O–H ($\nu_1, \nu_3$).
   - Повсеместно присутствует в атмосферах холодных звёзд (M, L, T, Y-карликов), протозвёздных ледяных мантиях и экзопланетных атмосферах.
2. **Метан CH₄ (3.30 мкм, Детектор D4):**
   - Фундаментальная полоса $\nu_3$ валентного колебания C–H (3.2 – 3.4 мкм).
   - Главный спектроскопический маркер коричневых карликов классов T и Y (WISE 0855−0714, ε Indi Ba/Bb) и холодных планет-гигантов. Отмечает химический переход CO $\rightarrow$ CH₄ при температурах фотосфер ниже ~1400 K.
3. **Углекислый газ CO₂ (4.27 мкм, Детектор D5):**
   - Сильнейшая фундаментальная колебательная полоса $\nu_3$ (4.2 – 4.35 мкм).
   - Важнейший компонент межзвёздных льдов, ключевой индикатор состава атмосфер землеподобных планет и биомаркерная диагностика.
4. **Угарный газ CO (4.67 мкм, Детектор D6):**
   - Фундаментальная ротационно-колебательная полоса 1–0 (4.6 – 4.8 мкм).
   - Главный носитель углерода в горячих атмосферах (T > 1400 K), протопланетных аккреционных дисках (RW Aurigae), звёздах-гигантах и пульсирующих переменных типа Миры (R Draconis).

- **Пары детекторов:** D1+D4, D2+D5, D3+D6 имеют абсолютно идентичный `obsid` и экспонируются синхронно через дихроичные светоделители (одна точка неба отражается в коротковолновый детектор и проходит в длинноволновый).
- **Механизм LVF:** Длина волны плавно зависит от координаты $X$ или $Y$ на детекторе. Для любого пикселя вырезки точная пара $(\lambda, \Delta\lambda)$ восстанавливается через HDU `WCS-WAVE` (`pixel_wavelength()`).
- **Размер пикселя:** 6.15″ (физический масштаб FPA SPHEREx).

### Выводы для архитектуры
1. **Эпох 3–4, а не десятки.** Правило «разрыв > 3 суток» дробит один 6‑месячный обзор на много кусков, каждый на своей длине волны. Использовать **разрыв > 60 дней**.
2. **R Dra лежит у полюса эклиптики и снимается непрерывно.** Кластеризация даст одну эпоху. Нужен запасной вариант: **бины по 30 дней**, если эпох < 2. Для кривой блеска это даже лучше: у R Dra период около 245.6 дней, и он идеально непрерывно покрыт.
3. **Сдвиг всего 1–2 пикселя.** Голый blink движение почти не покажет. Обязательно нужны: diff внутри одного детектора, апсемплинг при зуме, стрелки собственного движения (Gaia/CatWISE) и **сравнение с WISE (база 15 лет) как основная фича, а не бонус**.
4. **Снимков сотни (R Dra 650).** Нужен лимит: не больше N вырезок на детектор на эпоху (например, 8 штук, равномерно по времени).
5. **Для коричневых карликов по умолчанию D6** (затем D5): там они ярче всего. В D1–D2 WISE 0855 практически не виден из-за экспоненциального завала Вина и поглощения метана.
6. **Diff — только внутри одного детектора.** В режиме `all` разные эпохи содержат разную смесь длин волн, и это даёт ложные «изменения».

## 6. Первые реальные diff (14.11, ~14:35) — что увидели
- **ε Ind B (D6, 2025-04-29 → 2026-09-22): движение ВИДНО.** Пара «белое+чёрное» стоит в 17 px к востоку и 10 px к югу от центра — ровно там, где цель должна быть по собственному движению (~4.7″/год) от координат SIMBAD J2000. Направление пары (на восток и юг) совпадает с PM. **Конвейер подтверждён на реальных данных.**
- **Barnard (D2): звезды в кадре нет.** SIMBAD отдаёт координаты на J2000; за ~26 лет Barnard ушёл на **268″ к северу**, а половина FOV — 150″. → **Обязательно переносить координаты цели на эпоху SPHEREx** (`core.targets`: `PRESET_PM` + `propagate()`, центр — эпоха 2025.9). В бэкенде: `/api/resolve` возвращает `pm` и `coordinate_epoch`.
- **WISE 0855 (D6): шумно.** Цель ~125″ к западу от координат AllWISE (эпоха ≈ 2010.5) — у края кадра; первая эпоха D6 — всего 3 снимка. → PM-поправка + diff по «полным» эпохам.
- **У всех звёзд поля — маленькие пары «белое+чёрное» случайной ориентации.** Это артефакт: PSF SPHEREx сравним с пикселем 6.15″ (недодискретизирован), меняется по детектору, плюс интерполяция при репроекции. Отличие настоящего движения: пара **сильнее**, **ориентирована по PM** и **совпадает с кольцами предсказанных положений**. → В UI обязательно рисовать кольца/стрелки PM, иначе пользователь примет артефакты за открытия.

## 7. Справочные заметки по 5 конкурсным объектам (автор неизвестен, не проверено — сверять с литературой)

### 1. Barnard's Star (GJ 699, HIP 87937)
- **Класс:** Красный карлик спектрального класса M4.0V, $T_\mathrm{eff} \approx 3130$ K.
- **Астрометрия:** $\alpha = 269.452083^\circ$, $\delta = +4.693364^\circ$ (эпоха J2000.0). Параллакс $\varpi = 546.976 \pm 0.297$ mas, расстояние 1.828 пк = 5.96 св. лет.
- **Кинематика:** $\mu_\alpha\cos\delta = -801.55$ mas/yr, $\mu_\delta = +10362.39$ mas/yr. Полное собственное движение $\mu = 10.393''$/год (рекордное на небесном своде!). Позиционный угол движения $\theta \approx 355.6^\circ$ (практически строго на север с микросмещением к западу).
- **Смещение к эпохе SPHEREx (2025.9):** за 25.9 лет смещение по склонению составляет $+268.4''$ (более 4.4 угловых минут!). Без переноса координат в стандартном поле $300''$ звезда оказывается за пределами кадра. Смещение за время работы миссии SPHEREx (403 дня) составляет $11.5''$ (1.87 пикселя), давая безупречный биполярный диполь в `diff`.
- **Спектроскопия:** Высокий поток в ближнем ИК (D1: 0.75–1.12 мкм, D2: 1.10–1.65 мкм). Насыщен полосами поглощения водяного пара $H_2O$ на 1.4, 1.9, 2.7–3.0 мкм и полосами CO на 2.3 мкм (обертон) и 4.67 мкм (основная полоса). Оптимальный детектор: D2.

### 2. WISE J085510.83−071442.5 (WISE 0855)
- **Класс:** Ультрахолодный коричневый субкарлик / планемо спектрального класса Y2, масса $\sim 3\text{--}10\,M_\mathrm{Jup}$, эффективная температура $T_\mathrm{eff} \approx 250 \pm 15$ K (холоднее точки замерзания воды!). Самый холодный изолированный компактный объект за пределами Солнечной системы.
- **Астрометрия:** $\alpha = 133.79513^\circ$, $\delta = -7.24515^\circ$ (эпоха открытия AllWISE 2010.5). Параллакс $\varpi \approx 448 \pm 8$ mas, расстояние 2.23 пк = 7.27 св. лет.
- **Кинематика:** $\mu_\alpha\cos\delta = -8118$ mas/yr, $\mu_\delta = +680$ mas/yr (Luhman & Esplin 2016). Полное движение $\mu \approx 8.15''$/год.
- **Смещение к эпохе SPHEREx (2025.9):** за 15.4 года с момента AllWISE смещение на запад составило $\Delta\alpha\cos\delta \approx -124.3''$ (~20 пикселей SPHEREx!). За 374-дневную базу SPHEREx смещение составляет $8.29''$ (1.35 пикселя).
- **Спектроскопия:** При температуре 250 K закон смещения Вина даёт максимум около 11.6 мкм. В диапазоне D1–D3 (0.75–2.44 мкм) фотонный поток экспоненциально подавлен (практически нулевой). В полосе D4 (2.40–3.85 мкм) излучение блокируется фундаментальными полосами поглощения метана $CH_4$ (3.3 мкм) и водяного льда/пара $H_2O$ (3.0 мкм). Основное окно прозрачности атмосферы приходится на полосу **4.5–5.0 мкм**. Детектор **D6 (4.41–5.01 мкм)** — единственно правильный выбор по умолчанию!

### 3. Epsilon Indi Ba/Bb (HD 209100 BC)
- **Класс:** Двойная система коричневых карликов раннего и позднего T-классов (T1 + T6), вращающаяся вокруг звезды K5V Epsilon Indi A на расстоянии 1459 а.е. Эффективные температуры: $T_\mathrm{Ba} \approx 1300$ K, $T_\mathrm{Bb} \approx 900$ K.
- **Астрометрия:** $\alpha = 331.04383^\circ$, $\delta = -56.78269^\circ$ (эпоха J2000.0). Параллакс $\varpi = 274.84$ mas, расстояние 3.638 пк = 11.87 св. лет.
- **Кинематика:** Общее собственное движение с родительской звездой: $\mu_\alpha\cos\delta = +3961.0$ mas/yr, $\mu_\delta = -2539.0$ mas/yr. Полный вектор $\mu \approx 4.705''$/год в направлении юго-востока ($\theta \approx 122.7^\circ$).
- **Смещение к эпохе SPHEREx (2025.9):** за 25.9 лет смещение составило $+102.6''$ по RA и $-65.8''$ по Dec. За наблюдательную базу 526 дней смещение составляет $6.78''$ (1.10 пикселя), формируя чёткую разностную сигнатуру.
- **Спектроскопия:** Классический эталон T-карликов. Глубокое поглощение метаном $CH_4$ на 3.3 мкм (D4) и 1.66 мкм (D3), поглощение водяным паром $H_2O$ на 1.4, 1.9 и 3.0 мкм. Пик контраста и максимальное отношение сигнал/шум достигаются в детекторе **D6 (4.41–5.01 мкм)**.

### 4. RW Aurigae (RW Aur, HD 240764)
- **Класс:** Молодая двойная система классических звёзд типа T Тельца (CTTS, RW Aur A спектрального класса K3-K5e и RW Aur B класса K5-M0e с разделением 1.4″), возраст $\sim 5$ млн лет, область звездообразования в Тельце-Возничем.
- **Астрометрия:** $\alpha = 76.95642^\circ$, $\delta = +30.40141^\circ$ (J2000.0). Параллакс $\varpi = 6.16$ mas, расстояние $\sim 160$ пк (520 св. лет).
- **Кинематика:** $\mu_\alpha\cos\delta = +1.2$ mas/yr, $\mu_\delta = -22.3$ mas/yr. За 1.4 года работы SPHEREx собственное движение составляет всего $0.031''$ (0.005 пикселя) — объект полностью неподвижен на сетке SPHEREx.
- **Физический механизм переменности:** Система известна катастрофическими глубокими затмениями (падение блеска $\Delta V$ до 3–4 звездных величин на месяцы и годы). Причина — приливное разрушение околозвёздного протопланетного диска компонента A гравитационным пролётом компонента B с образованием приливного моста и протяжённых пылевых облаков, периодически экранирующих звезду.
- **Режим в приложении:** Режим `diff` не имеет смысла; необходим режим покадрового блинкования `frames` и анализ кривой блеска `lightcurve` в полосе D2 (1.10–1.65 мкм) для отслеживания оптической толщи околозвёздной пыли и инфракрасного избытка.

### 5. R Draconis (R Dra, HD 149880)
- **Класс:** Пульсирующий холодный красный гигант асимптотической ветви гигантов (AGB), долгопериодическая переменная типа Миры Кита спектрального класса M4e–M8e.
- **Астрометрия:** $\alpha = 248.16738^\circ$, $\delta = +66.75489^\circ$ (J2000.0). Параллакс $\varpi = 1.85$ mas, расстояние $\sim 540$ пк (1760 св. лет).
- **Кинематика:** $\mu_\alpha\cos\delta = -11.9$ mas/yr, $\mu_\delta = -11.6$ mas/yr. Смещение за время миссии $< 0.02''$ (0.003 пикселя) — пространственно стационарна.
- **Пульсации и фотометрия:** Период радиальных пульсаций $P \approx 245.6$ суток. Визуальная звёздная величина меняется от $V \approx 6.7^m$ до $13.2^m$ (амплитуда свыше 6.5 величин, фактор изменения видимой яркости $\sim 400$ раз!). В ИК диапазоне амплитуда составляет 1.5–2.5 величины.
- **Уникальное преимущество орбиты SPHEREx:** R Dra находится на высокой эклиптической широте ($\beta \approx +82.5^\circ$) в непосредственной близости от Северного эклиптического полюса (NEP). Солнечно-синхронная полярная орбита SPHEREx проходит через полярные шапки на каждом витке ($\approx 98$ мин, 14.6 витков в сутки). В архиве SPHEREx для R Dra доступно **более 650 экспозиций** с непрерывным шагом! Это позволяет построить беспрецедентную по плотности и качеству кривую блеска за 2 полных периода пульсаций (~500 суток). Оптимальный режим: `frames`, D2.

## 8. Полный реестр ловушек данных IRSA и применённых решений (Data Traps & Mitigations)

1. **Ловушка HTTP 200 "Server busy, retry later."**
   - *Проблема:* При пиковой нагрузке архив IRSA Cutout возвращает код 200 с MIME-типом `application/fits`, но в теле передаёт 25-байтовую строку `Server busy, retry later.`. Стандартные парсеры FITS крашатся с фатальной ошибкой `OSError: Header missing SIMPLE`.
   - *Решение:* Проверка первых байт ответа на префикс `b"SIMPLE"`. При обнаружении псевдоответа запрос квалифицируется как временный сбой с экспоненциальной задержкой (5 $\rightarrow$ 30 с) до 6 повторов (`core.spherex.fetch_cutout`).
2. **Ловушка HTTP 503 Service Unavailable / Таймауты:**
   - *Проблема:* Во время судейских тестов и массовых запросов хакатона IRSA дропает до 10–15% запросов.
   - *Решение:* Архитектурный пул фоновых задач (`JobQueue`, `ThreadPoolExecutor(max_workers=4)`), асинхронный статус 202 + поллинг через SSE/REST, а главное — предварительный прогрев и коммит статического кэша всех 5 конкурсных объектов (`viewer.static_cache`). Пресеты мгновенно отдают 200 OK даже при отключённой сети.
3. **Бутылочное горлышко TAP (20–60 с) vs SIA2 (9 с):**
   - *Проблема:* Запросы через TAP по таблице `spherex.plane` требуют сложного пространственного `CONTAINS(POINT, poly)` и выполняются 20–60 секунд на точку.
   - *Решение:* Переход на протокол SIA2 (`COLLECTION=spherex_dr1`) с радиусом в градусах. Поиск занимает 1.4–9.2 с (ускорение в 3–6 раз). Метаданные кэшируются на диске по хэшу `(ra, dec, radius)`.
4. **Объём FITS вырезок и нехватка памяти (HDU EPSF):**
   - *Проблема:* 24 вырезки одного блинка весят свыше 100 МБ из-за 3D-куба PSF (`HDU EPSF` ~4 МБ на вырезку). На бесплатном сервере Render (512 МБ RAM) одновременная загрузка вызывает Out-Of-Memory.
   - *Решение:* Метод `fetch_cutout` при сохранении в локальный кэш сохраняет только `KEEP_HDUS = ("IMAGE", "FLAGS", "VARIANCE", "ZODI", "WCS-WAVE")`, отбрасывая `EPSF`. Вес файла снижается на 85% до ~0.5 МБ.
5. **Ловушка эпохи координат J2000 для быстрых звёзд (Звезда Барнарда):**
   - *Проблема:* SIMBAD и CDS Sesame возвращают координаты на эпоху J2000.0. Звезда Барнарда со скоростью $10.39''$/год сместилась к 2025.9 году на $268''$ к северу. При вырезке $300''$ (радиус $150''$) звезда вообще не попадает в кадр.
   - *Решение:* Модуль `core.targets.propagate()` вычисляет положение объекта на эпоху SPHEREx 2025.9 и центрирует вырезку именно на это место. В метаданные ответа добавляются `catalog_ra/dec`, `coordinate_epoch` и `pm_mas_yr`.
6. **Ловушка битовых флагов FLAGS (Бит 21 SOURCE):**
   - *Проблема:* Бит 21 (`SOURCE`) устанавливается конвейером обработки вокруг любого известного каталожного источника. Вокруг ярких звёзд он покрывает 100% пикселей. Маска `FLAGS != 0` превращает кадр в сплошное пустое поле `NaN`.
   - *Решение:* Разделение политики маскирования: `DISPLAY_FLAG_POLICY` исключает из отображения только реальные дефекты (TRANSIENT, SUR_ERROR, NONFUNC, DICHROIC, HOT, COLD, PHANMISS, STREAK, SNOWBALL, HALO), оставляя `SOURCE`, `OVERFLOW` и `PERSIST` видимыми.
7. **Ловушка фонового зодиакального света (ZODI HDU):**
   - *Проблема:* В Level 2 продуктах SPHEREx слой `IMAGE` содержит сырую яркость, из которой **не вычтен зодиакальный фон**. Фоновая яркость ZODI меняется в зависимости от угла к Солнцу от эпохи к эпохе, маскируя реальные изменения объектов.
   - *Решение:* В модуле `display_prepare()` автоматически выполняется поэлементное вычитание `IMAGE - ZODI`.
8. **Ловушка спектрального хроматизма в Diff-режиме:**
   - *Проблема:* Фильтры LVF плавно меняют длину волны. Если сформировать diff между разными детекторами (например, D1 и D2) или в режиме `all`, спектральный наклон звёзд поля создаёт сотни ложных переменных и движущихся объектов.
   - *Решение:* Строгий запрет на междетекторный diff. Режим `diff` работает исключительно внутри одного детектора (монохроматический diff).
9. **Ловушка фантомных объектов CatWISE вокруг ярких звёзд:**
   - *Проблема:* Вокруг насыщенных звёзд (Барнард $G = 8.2$) алгоритмы CatWISE детектируют десятки ложных источников с псевдодвижением в лучах дифракции.
   - *Решение:* Функция `catalogs.project()` фильтрует некоррелированные с Gaia источники CatWISE в радиусе $180''$ от звёзд ярче $G = 9.5$.
10. **Ловушка дублирования треков быстрых объектов в CatWISE:**
    - *Проблема:* Движущиеся объекты (WISE 0855, Barnard) регистрировались телескопом WISE в разные проходы, образуя в CatWISE несколько записей с разными эпохами `meanobsmjd`.
    - *Решение:* Каждый источник CatWISE переносится по собственному вектору движения на опорную эпоху 2025.9, после чего дубликаты в радиусе $8''$ автоматически сливаются.
